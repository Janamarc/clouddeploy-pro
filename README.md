MotionX Showcase 
A modern animated frontend showcase website deployed using a complete CI/CD pipeline with GitHub Actions, AWS EC2, Linux, and Nginx.

 Live Demo
Frontend Hosted on GitHub Pages:
https://janasri-16.github.io/motionx-showcase/

 Project Overview
MotionX Showcase is an interactive frontend project created to demonstrate:
- Modern frontend development
- Responsive UI design
- Advanced CSS animations
- JavaScript interactions
- AWS EC2 deployment
- CI/CD automation using GitHub Actions
- Linux server hosting with Nginx

This project highlights both frontend development skills and DevOps deployment workflow integration.

 Tech Stack

CI/CD Pipeline Workflow

text
Developer Push
      ↓
GitHub Repository
      ↓
GitHub Actions Trigger
      ↓
Automated Build & Deployment
      ↓
AWS EC2 Instance
      ↓
Nginx Web Server
The deployment workflow automatically updates the hosted application whenever new changes are pushed to GitHub.

 AWS EC2 Hosting
This project is also hosted on an AWS EC2 Ubuntu instance configured with Nginx.
